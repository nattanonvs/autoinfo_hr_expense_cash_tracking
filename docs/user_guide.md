# คู่มือการใช้งาน

## 1. โมดูลนี้คืออะไร

โมดูลนี้ช่วยงานเบิกค่าใช้จ่ายของพนักงานที่สำรองจ่ายเองก่อน แล้วค่อยส่งเอกสารเพื่อขอเงินคืนทีหลัง

ระบบนี้ช่วยให้ทำงานได้เป็นขั้นตอน เช่น:

- สร้างรายการค่าใช้จ่าย
- รวมหลายรายการเป็น `Expense Sheet`
- ส่งตรวจ
- อนุมัติ
- ตีกลับเพื่อแก้ไข
- ส่งใหม่
- ปิดงานคืนเงินสด

รอบปัจจุบันของโมดูลเพิ่ม `Expense Category`

คำนี้หมายถึง “หมวดค่าใช้จ่ายแบบอ่านง่าย”

ตัวอย่างเช่น:

- ค่าน้ำมัน
- ค่าเดินทาง
- ค่าอุปกรณ์สำนักงาน

พนักงานจึงไม่ต้องเลือก `product` แบบบัญชีด้วยตัวเอง

ระบบจะช่วย map ไปให้เอง

## 2. โมดูลนี้ทำอะไรได้บ้าง

- ให้พนักงานเลือก `Expense Category` แทนการเลือก `product` เอง
- เติม `product` ให้อัตโนมัติจากหมวดที่ตั้งไว้
- ซ่อน `product` จากพนักงานทั่วไป
- ให้บัญชีและผู้จัดการยังเห็น `product` จริงได้
- บังคับให้กรอก `Analytic Account` ก่อนส่งอนุมัติ
- บล็อกการส่งเอกสารถ้าหมวดค่าใช้จ่ายตั้งค่าไม่ถูก
- รองรับการตีกลับและส่งใหม่
- ให้ฝ่ายการเงินปิดงานคืนเงินสด
- ส่งออก Excel ได้ทั้งแบบรายใบและแบบสรุป

## 3. ก่อนเริ่มใช้ ต้องเตรียมอะไรบ้าง

1. ต้องติดตั้งโมดูลนี้แล้ว
2. ต้องมีสิทธิ์ผู้ใช้ที่ถูกต้อง
3. ต้องมี `Analytic Account` ให้เลือก
4. ต้องมี `Expense Category` ที่ผูกกับ `Product` แล้ว
5. ต้องมีสายอนุมัติ `Tier Validation` สำหรับ `Expense Sheet`

ถ้ายังไม่ครบข้อใดข้อหนึ่ง

การใช้งานอาจไม่ผ่าน หรือส่งเอกสารไม่ได้

## 4. คู่มือแบบแยกตามคนใช้งาน

คู่มือนี้แบ่งเป็น 2 กลุ่มใหญ่

- พนักงานผู้ส่งเบิก
- แอดมิน / หัวหน้า / บัญชี / การเงิน

## 5. คู่มือสำหรับพนักงานผู้ส่งเบิก

### 5.1 เริ่มจากตรงไหน

1. เข้า Odoo
2. ไปที่เมนู `Expenses`
3. กดปุ่มสร้างรายการใหม่

### 5.2 ต้องกรอกอะไรบ้าง

ตอนสร้าง `Expense` ให้กรอกทีละช่องดังนี้

1. `ชื่อรายการ`
2. `วันที่`
3. `จำนวนเงิน`
4. `รายละเอียด`
5. `Expense Category`
6. `Analytic Account`
7. แนบไฟล์หลักฐาน ถ้าบริษัทกำหนดให้แนบ

สิ่งสำคัญ:

- พนักงานจะเห็น `Expense Category`
- พนักงานจะไม่ต้องเลือก `Product` เอง
- แต่ยังต้องใส่ `Analytic Account`

### 5.3 วิธีสร้าง Expense แบบทีละขั้น

1. ไปที่ `Expenses`
2. กดสร้างรายการ
3. พิมพ์ชื่อรายการ เช่น `ค่าน้ำมันไปพบลูกค้า`
4. เลือกวันที่ที่จ่ายเงินจริง
5. ใส่จำนวนเงิน
6. เลือก `Expense Category` ที่ใกล้ที่สุด
7. เลือก `Analytic Account`
8. ใส่รายละเอียดเพิ่มถ้าจำเป็น
9. แนบใบเสร็จหรือหลักฐาน
10. กดบันทึก

### 5.4 ถ้าไม่แน่ใจว่าจะเลือกหมวดไหนดี

ให้ทำตามนี้

1. อ่านชื่อหมวดทีละรายการ
2. เลือกหมวดที่ตรงที่สุด
3. ถ้ายังไม่แน่ใจ ให้ถามหัวหน้าหรือบัญชี
4. อย่าเดาแบบสุ่ม

เหตุผล:

- ถ้าเลือกหมวดผิด บัญชีอาจตีกลับให้แก้
- ถ้าหมวดนั้นตั้งค่าไม่ครบ ระบบอาจส่งอนุมัติไม่ผ่าน

### 5.5 วิธีรวมหลายรายการเป็น Expense Sheet

เมื่อสร้าง `Expense` หลายรายการแล้ว

ให้รวมเป็น `Expense Sheet`

ขั้นตอน:

1. เปิดรายการ `Expense` ที่ต้องการ
2. เลือกหลายรายการที่ต้องการรวม
3. กดสร้าง `Expense Sheet`
4. ตรวจว่ารายการครบ
5. ตรวจยอดรวม
6. กดบันทึก

### 5.6 วิธีส่งขออนุมัติ

1. เปิด `Expense Sheet`
2. ตรวจข้อมูลอีกครั้ง
3. กดปุ่มส่งขออนุมัติ

ถ้ากดแล้วไม่ผ่าน

มักเกิดจากสาเหตุนี้:

- ยังไม่ได้ใส่ `Analytic Account`
- `Expense Category` ผูกกับ `Product` ไม่ถูก
- มีการแก้ `Product` จนไม่ตรงกับหมวด

### 5.7 หลังส่งแล้วจะเกิดอะไรขึ้น

เอกสารจะไปตามรอบตรวจของบริษัท เช่น:

1. หัวหน้าตรวจ
2. บัญชีตรวจ
3. ผู้อนุมัติขั้นสุดท้ายตรวจ

คุณอาจเห็นสถานะเปลี่ยนไปตามขั้นตอน

### 5.8 ถ้าเอกสารถูกตีกลับ ต้องทำอย่างไร

1. เปิด `Expense Sheet` ที่ถูกตีกลับ
2. อ่านเหตุผลที่ถูกส่งกลับ
3. เปิดรายการที่เกี่ยวข้อง
4. แก้ข้อมูลให้ถูก
5. ตรวจใหม่อีกครั้ง
6. ส่งขออนุมัติใหม่

สิ่งที่ควรเช็กเป็นพิเศษ:

- จำนวนเงิน
- ใบเสร็จ
- รายละเอียด
- `Analytic Account`
- `Expense Category`

### 5.9 ตัวอย่างจริงสำหรับพนักงาน

ตัวอย่าง:

1. คุณสำรองจ่ายค่าน้ำมัน 800 บาท
2. เข้า `Expenses`
3. สร้างรายการใหม่
4. ใส่ชื่อ `ค่าน้ำมันไปพบลูกค้า`
5. ใส่วันที่จริง
6. ใส่จำนวนเงิน `800`
7. เลือก `Expense Category = ค่าน้ำมัน`
8. เลือก `Analytic Account`
9. แนบใบเสร็จ
10. บันทึก
11. ถ้ามีหลายใบ ให้รวมเป็น `Expense Sheet`
12. กดส่งขออนุมัติ

## 6. คู่มือสำหรับแอดมิน / หัวหน้า / บัญชี / การเงิน

### 6.1 แอดมินหรือผู้จัดการ Expense ต้องตั้งค่าอะไร

ก่อนให้พนักงานใช้งานจริง

ต้องตั้งค่า `Expense Category` ก่อน

ขั้นตอน:

1. ไปที่ `Expenses > Configuration > Expense Categories`
2. กดสร้างรายการใหม่
3. ใส่ `Name`
4. ใส่ `Code`
5. เลือก `Product` ที่ต้องใช้จริง
6. เลือก `Company` ถ้ามีหลายบริษัท
7. กดบันทึก

คำแนะนำ:

- ใช้ชื่อหมวดที่พนักงานอ่านแล้วเข้าใจทันที
- ไม่ควรใช้ชื่อที่เป็นรหัสบัญชีล้วน
- ถ้าเปลี่ยน `Product` ควรทดสอบใช้งานก่อน

### 6.2 หัวหน้าหรือผู้อนุมัติต้องทำอะไร

1. เปิด `Expense Sheet`
2. ตรวจข้อมูลรายการ
3. ดูความสมเหตุสมผลของค่าใช้จ่าย
4. ถ้าถูกต้อง ให้อนุมัติ
5. ถ้าไม่ถูกต้อง ให้ตีกลับพร้อมเหตุผล

สิ่งที่ควรเขียนตอนตีกลับ:

- บอกให้ชัดว่าแก้อะไร
- ใช้ประโยคสั้น ๆ
- ยกตัวอย่างรายการที่ผิด

ตัวอย่าง:

- `กรุณาแนบใบเสร็จเพิ่ม`
- `ยอดเงินบรรทัดที่ 2 ไม่ตรง`
- `เลือกหมวดค่าใช้จ่ายใหม่ให้ถูกต้อง`

### 6.3 Accounting Reviewer ต้องเช็กอะไร

1. เปิด `Expense` หรือ `Expense Sheet`
2. เช็กว่า `Expense Category` ตรงกับ `Product`
3. เช็กข้อมูลประกอบทางบัญชี
4. เช็กเอกสารแนบ
5. อนุมัติหรือส่งกลับ

จุดสำคัญ:

- กลุ่มบัญชีจะยังเห็น `Product`
- ใช้ดูว่าระบบ map จากหมวดมาได้ถูกต้องหรือไม่

### 6.4 ฝ่ายการเงินต้องทำอะไร

เมื่อเอกสารผ่านครบทุกขั้นแล้ว

ให้ทำดังนี้

1. เปิด `Expense Sheet`
2. ตรวจว่าเอกสารพร้อมจ่ายคืน
3. จ่ายเงินให้พนักงาน
4. กด `Mark Cash Reimbursed`
5. ตรวจวันที่และข้อมูลในแชตเตอร์

### 6.5 ถ้าพนักงานบอกว่าส่งไม่ผ่าน ให้เช็กอะไร

1. เช็กว่ามี `Analytic Account` ครบทุกบรรทัดหรือไม่
2. เช็กว่า `Expense Category` ผูกกับ `Product` แล้วหรือยัง
3. เช็กว่า `Product` ถูกแก้จนไม่ตรงกับหมวดหรือไม่
4. เช็กสิทธิ์ผู้ใช้
5. เช็กว่าขั้นอนุมัติถูกตั้งไว้ครบหรือไม่

## 7. Best Practice แบบง่าย

- ตั้งชื่อหมวดให้เข้าใจง่าย
- ทดสอบ 1 รายการก่อนเปิดใช้จริง
- ไม่ให้พนักงานเลือก `Product` เอง
- ให้บัญชีเป็นคนดูแล mapping
- ถ้าตีกลับ ควรเขียนเหตุผลให้ชัด

## 8. สิ่งที่ต้องระวัง

- ถ้าไม่มี `Analytic Account` จะส่งไม่ได้
- ถ้าหมวดค่าใช้จ่ายตั้งค่าไม่ครบ จะส่งไม่ได้
- ถ้า `Product` ไม่ตรงกับหมวด ระบบจะ block
- ผู้ใช้ทั่วไปจะไม่เห็นหน้า config ของหมวด
- ถ้าแก้โครงสร้างหมวด ควรทดสอบอีกครั้ง

## 9. ถ้ามีปัญหา ให้ทำตามนี้

### ปัญหา 1: ส่งเอกสารไม่ได้

ให้เช็ก:

1. ใส่ `Analytic Account` แล้วหรือยัง
2. เลือก `Expense Category` แล้วหรือยัง
3. หมวดนั้นผูก `Product` แล้วหรือยัง

### ปัญหา 2: บัญชีบอกว่าหมวดไม่ตรง

ให้ทำดังนี้:

1. เปิดรายการเดิม
2. ตรวจหมวดที่เลือก
3. แก้ให้ตรง
4. ส่งใหม่

### ปัญหา 3: ไม่เห็นไฟล์ Excel

ให้เช็ก:

1. ติดตั้ง `report_xlsx` แล้วหรือยัง
2. ผู้ใช้มีสิทธิ์ใช้งานหรือไม่

### ปัญหา 4: ไม่เห็นเมนู Expense Categories

ให้เช็ก:

1. ผู้ใช้อยู่ในกลุ่มผู้จัดการ Expense หรือไม่
2. โมดูลอัปเกรดล่าสุดแล้วหรือยัง

## 10. สรุปสั้น ๆ

- พนักงานเลือก `Expense Category`
- ระบบเติม `Product` ให้เอง
- พนักงานไม่ต้องแตะข้อมูลบัญชีลึก
- บัญชีและผู้จัดการยังตรวจของจริงได้
- ถ้าข้อมูลไม่ครบ ระบบจะไม่ยอมให้ส่ง
- ถ้าถูกตีกลับ ต้องแก้แล้วส่งใหม่
