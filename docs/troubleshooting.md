# วิธีแก้ปัญหา

## 1. เอกสารนี้ใช้ยังไง

ถ้าคุณเจอปัญหา

ให้ใช้เอกสารนี้แบบทีละขั้น

ลำดับที่แนะนำคือ:

1. ดูว่าอาการที่เจอคืออะไร
2. อ่านสาเหตุที่เป็นไปได้
3. เช็กทีละข้อ
4. แก้ทีละขั้น
5. ทดสอบใหม่

## 2. ปัญหา: ส่ง Expense Sheet ไม่ได้

### อาการที่เจอ

- กดส่งขออนุมัติแล้วไม่ผ่าน
- ระบบขึ้นข้อความเตือน
- เอกสารยังไม่ไปขั้นถัดไป

### สาเหตุที่เป็นไปได้

- บางบรรทัดไม่มี `Analytic Account`
- `Expense Category` ยังผูกกับ `Product` ไม่ถูก
- `Product` ถูกแก้จนไม่ตรงกับหมวด
- เอกสารยังมีเงื่อนไขใน `Tier Validation`

### วิธีเช็ก

1. เปิด `Expense Sheet`
2. เปิดดูทุกบรรทัดของค่าใช้จ่าย
3. เช็กว่าทุกบรรทัดมี `Analytic Account`
4. เช็กว่าทุกบรรทัดเลือก `Expense Category` ถูกต้อง
5. ถ้าคุณเป็นบัญชีหรือผู้จัดการ ให้เช็กว่า `Product` ตรงกับหมวด
6. เช็กสถานะเอกสารในสายอนุมัติ

### วิธีแก้

1. ใส่ `Analytic Account` ให้ครบ
2. แก้ `Expense Category` ให้ตรง
3. ถ้า mapping ผิด ให้ผู้จัดการไปแก้ที่ `Expense Categories`
4. บันทึกเอกสาร
5. กดส่งใหม่

### วิธีเช็กว่าหายแล้ว

1. กดส่งขออนุมัติอีกครั้ง
2. ดูว่าสถานะเปลี่ยนเป็นรอตรวจหรือไม่

## 3. ปัญหา: ฝ่ายการเงินกดคืนเงินไม่ได้

### อาการที่เจอ

- ไม่เห็นปุ่ม `Mark Cash Reimbursed`
- กดแล้ว error
- กดแล้วไม่เปลี่ยนสถานะ

### สาเหตุที่เป็นไปได้

- ผู้ใช้ไม่มีสิทธิ์
- เอกสารยังไม่ผ่านการอนุมัติครบ
- เปิดเอกสารผิดหน้า

### วิธีเช็ก

1. เช็กว่าผู้ใช้อยู่ในกลุ่ม `group_expense_cash_reimbursement_manager`
2. เปิดเอกสารจากหน้า `Expense Sheet`
3. เช็กว่าเอกสารผ่านขั้นอนุมัติที่ต้องผ่านแล้ว

### วิธีแก้

1. ให้แอดมินเพิ่มสิทธิ์ผู้ใช้
2. รอให้เอกสารผ่านครบทุกขั้นก่อน
3. เปิดเอกสารจากหน้า `Expense Sheet` แล้วลองใหม่

### วิธีเช็กว่าหายแล้ว

1. กดปุ่มอีกครั้ง
2. ดูว่าสถานะคืนเงินสดเปลี่ยนหรือไม่
3. ดูข้อความใน `Chatter`

## 4. ปัญหา: ไม่เห็นข้อความตีกลับ

### อาการที่เจอ

- เอกสารถูกส่งกลับ แต่ไม่เห็นเหตุผล

### สาเหตุที่เป็นไปได้

- ยังไม่ได้เปิดเอกสารใบที่ถูกต้อง
- ยังไม่ได้ดูใน `Chatter`
- เอกสารถูกเปลี่ยนสถานะ แต่ผู้ใช้ยังไม่ได้รีเฟรชหน้า

### วิธีเช็ก

1. เปิด `Expense Sheet` ที่ถูกตีกลับ
2. เลื่อนดู `Chatter`
3. ดูว่ามีเหตุผลการตีกลับในฟอร์มหรือไม่
4. ดูว่า `returned_for_resubmission` ถูกเปิดแล้วหรือไม่

### วิธีแก้

1. รีเฟรชหน้า
2. เปิดเอกสารอีกครั้ง
3. ตรวจข้อความใน `Chatter`
4. ถ้ายังไม่เห็น ให้ผู้มีสิทธิ์ลองตรวจจากอีกบัญชีผู้ใช้

## 5. ปัญหา: export Excel ไม่ได้

### อาการที่เจอ

- กด export แล้วไม่เกิดไฟล์
- กด wizard แล้วไม่ไปต่อ
- ได้ไฟล์ว่าง

### สาเหตุที่เป็นไปได้

- ยังไม่ได้ติดตั้ง `report_xlsx`
- เปิดเอกสารผิดใบ
- เลือกช่วงวันที่ไม่ถูก
- ในช่วงวันที่นั้นไม่มีข้อมูล

### วิธีเช็ก

1. ตรวจว่าโมดูล `report_xlsx` ติดตั้งแล้ว
2. ถ้าเป็นแบบใบเดี่ยว ให้เช็กว่าเปิด `Expense Sheet` ถูกใบ
3. ถ้าเป็นแบบหลายใบ ให้เช็กวันที่ใน wizard
4. เช็กว่าช่วงวันที่มีข้อมูลจริง

### วิธีแก้

1. ติดตั้ง `report_xlsx` ถ้ายังไม่มี
2. เปิดเอกสารใบที่ถูกต้อง
3. เลือกช่วงวันที่ใหม่
4. ลอง export อีกครั้ง

## 6. ปัญหา: เปิดเมนู config ไม่ได้

### อาการที่เจอ

- ไม่เห็นเมนู `Expense Categories`
- คลิกแล้วเปิดไม่ได้

### สาเหตุที่เป็นไปได้

- ผู้ใช้ไม่มีสิทธิ์ที่เกี่ยวข้อง
- โมดูลยังอัปเกรดไม่ครบ
- หน้า Odoo ยังไม่รีเฟรช

### วิธีเช็ก

1. เช็กสิทธิ์ผู้ใช้
2. เช็กว่าโมดูลติดตั้งและอัปเกรดครบ
3. ลองรีเฟรชหน้า Odoo

### วิธีแก้

1. ให้แอดมินเพิ่มสิทธิ์ที่ถูกต้อง
2. อัปเกรดโมดูลใหม่
3. เข้าใหม่อีกครั้ง

## 7. ปัญหา: พนักงานไม่เห็น Expense Category

### อาการที่เจอ

- เปิดฟอร์ม `Expense` แล้วไม่เห็นช่องหมวดค่าใช้จ่าย

### สาเหตุที่เป็นไปได้

- โมดูลยังไม่อัปเกรดเป็นเวอร์ชันล่าสุด
- view ยังไม่ถูกโหลดใหม่
- เปิดหน้าค้างจาก session เก่า

### วิธีเช็ก

1. รีเฟรชหน้า Odoo
2. ออกจากระบบแล้วเข้าใหม่
3. เช็กว่าโมดูลอัปเกรดล่าสุดแล้ว

### วิธีแก้

1. อัปเกรดโมดูล
2. รีสตาร์ต Odoo ถ้าจำเป็น
3. เปิดฟอร์มใหม่อีกครั้ง

## 8. ปัญหา: บัญชีเห็น Product ไม่ตรงกับหมวด

### อาการที่เจอ

- `Expense Category` เป็นอย่างหนึ่ง
- แต่ `Product` ที่เห็นไม่ตรงกัน

### สาเหตุที่เป็นไปได้

- มีการแก้ `Product` ภายหลัง
- mapping ของหมวดถูกเปลี่ยน
- ข้อมูลเก่าถูกสร้างก่อนตั้งค่าหมวด

### วิธีเช็ก

1. เปิดรายการ `Expense`
2. ดู `Expense Category`
3. ดู `Product`
4. เปิดหน้า config ของหมวดนั้น
5. ดูว่า `Product` ในหมวดตรงกับในรายการหรือไม่

### วิธีแก้

1. แก้หมวดหรือแก้รายการให้ตรงกัน
2. บันทึก
3. ส่งเอกสารใหม่ถ้าจำเป็น

## 9. แนวทางกู้คืนเบื้องต้น

ถ้าปัญหายังไม่หาย

ให้ทำตามนี้

1. สำรองฐานข้อมูลก่อนทุกครั้ง
2. หยุด Odoo service
3. รันอัปเกรดโมดูลใหม่อีกครั้งด้วย `--stop-after-init`
4. เปิด service
5. ทดสอบเมนูและปุ่มหลักใหม่
6. ทดสอบสร้าง `Expense` 1 รายการ
7. ทดสอบส่ง `Expense Sheet` 1 ใบ

## 10. เมื่อไรควรเรียกแอดมินหรือทีมพัฒนา

ให้แจ้งต่อเมื่อ:

- มี error ใน log ของ Odoo
- กดปุ่มแล้วขึ้น traceback
- export ไม่ได้แม้เช็กครบแล้ว
- menu หายทั้งระบบ
- อัปเกรดแล้ว view พัง
