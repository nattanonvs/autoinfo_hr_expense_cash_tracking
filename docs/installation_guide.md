# คู่มือติดตั้ง

## 1. เอกสารนี้ใช้ทำอะไร

เอกสารนี้ใช้ช่วย 2 กลุ่ม

- คนทั่วไปหรือหัวหน้าทีม ที่อยากรู้ภาพรวมว่าต้องเตรียมอะไร
- แอดมินระบบ ที่ต้องลงโมดูลจริงบน Odoo server

ถ้าคุณเป็นผู้ใช้ทั่วไป

ให้อ่านหัวข้อ `ภาพรวมก่อนเริ่ม`

ถ้าคุณเป็นแอดมิน

ให้อ่านทั้งเอกสารตั้งแต่ต้นจนจบ

## 2. ภาพรวมก่อนเริ่ม

ก่อนใช้โมดูลนี้

ต้องมีสิ่งนี้ก่อน:

1. มีระบบ `Odoo 15`
2. มีโฟลเดอร์ addon path คือ `/var/odoo/custom15_autoinfo`
3. มีโมดูลที่ต้องใช้ร่วมกันครบ
4. มีฐานข้อมูลที่พร้อมอัปเกรด
5. มีผู้ดูแลระบบที่มีสิทธิ์อัปเดตโมดูล

โมดูลที่ต้องมี:

- `hr_expense`
- `mail`
- `analytic`
- `report_xlsx`
- `base_tier_validation`
- `dtr_expense_tier_validation`

## 3. ก่อนติดตั้ง ต้องเตรียมอะไรบ้าง

ให้เช็กทีละข้อ

1. มีไฟล์โมดูลอยู่ที่:
   `/var/odoo/custom15_autoinfo/autoinfo_hr_expense_cash_tracking`
2. ชื่อโฟลเดอร์ต้องตรงกับชื่อโมดูล
3. แอดมินรู้ชื่อฐานข้อมูลที่จะอัปเกรด
4. แอดมินรู้ path ของ `odoo-bin`
5. สำรองฐานข้อมูลก่อนทุกครั้ง

คำแนะนำ:

- อย่าข้ามขั้นตอนสำรองข้อมูล
- ถ้าระบบใช้งานจริงอยู่ ควรทำในช่วงเวลาที่กระทบน้อย

## 4. วิธีติดตั้งใหม่แบบเข้าใจง่าย

ภาพรวมมี 5 ขั้น

1. วางโฟลเดอร์โมดูลให้ถูกที่
2. ตรวจ dependency
3. หยุด Odoo service
4. รันคำสั่งติดตั้งหรืออัปเกรด
5. เปิด service และทดสอบ

## 5. วิธีติดตั้งหรืออัปเกรดจริงสำหรับแอดมิน

### 5.1 วางโมดูล

ให้วางโมดูลไว้ที่:

`/var/odoo/custom15_autoinfo/autoinfo_hr_expense_cash_tracking`

### 5.2 หยุด service

```bash
sudo systemctl stop odoo15
```

### 5.3 ไปที่โฟลเดอร์ Odoo

```bash
cd /var/odoo/odoo15
```

### 5.4 รันคำสั่งอัปเกรดโมดูล

ให้แทน `<database_name>` ด้วยชื่อฐานข้อมูลจริง

```bash
./odoo-bin -c /etc/odoo.conf -d <database_name> -u autoinfo_hr_expense_cash_tracking --stop-after-init
```

### 5.5 เปิด service กลับ

```bash
sudo systemctl start odoo15
```

## 6. ถ้าต้องการติดตั้งครั้งแรกจาก Apps

บางระบบอาจใช้วิธีติดตั้งจากหน้า Apps

ให้ทำตามนี้:

1. วางโมดูลไว้ใน addon path ให้ถูก
2. รีสตาร์ต Odoo หรือ update apps list
3. เปิดหน้า `Apps`
4. ค้นหา `AUTO-INFO : HR Expense Cash Tracking`
5. กดติดตั้ง

ถ้าหาไม่เจอ

ให้เช็ก:

- path ของโมดูล
- สิทธิ์ไฟล์
- dependency

## 7. หลังติดตั้ง ต้องเช็กอะไรบ้าง

ให้เช็กทีละข้อ

1. ผู้ใช้เปิดเมนู `Expenses` ได้
2. ผู้จัดการเปิด `Expenses > Configuration > Expense Categories` ได้
3. สร้าง `Expense Category` ได้
4. สร้าง `Expense` โดยเลือกหมวดค่าใช้จ่ายได้
5. รวมเป็น `Expense Sheet` ได้
6. ส่งขออนุมัติได้
7. เห็นส่วน `Cash Reimbursement`
8. ลอง export `Detail XLSX`
9. ลอง export `Summary XLSX`

## 8. การตั้งค่าหลังติดตั้ง

### 8.1 ตั้งค่า Expense Category

1. ไปที่ `Expenses > Configuration > Expense Categories`
2. กดสร้าง
3. ใส่ชื่อหมวดที่พนักงานอ่านเข้าใจง่าย
4. ใส่ `Code`
5. ผูกกับ `Product`
6. บันทึก

### 8.2 ตั้งค่าสิทธิ์ผู้ใช้

ให้ตรวจกลุ่มผู้ใช้ที่เกี่ยวข้อง เช่น:

- พนักงานผู้ส่งเบิก
- ผู้จัดการ Expense
- ผู้ตรวจบัญชี
- ผู้จ่ายเงินคืน

### 8.3 ตรวจสายอนุมัติ

1. ตรวจ `Tier Definition`
2. ตรวจว่า flow อนุมัติครบตามที่บริษัทต้องการ

## 9. วิธีอัปเกรดเมื่อมีเวอร์ชันใหม่

1. สำรองฐานข้อมูล
2. วางไฟล์เวอร์ชันใหม่ทับของเดิม
3. หยุด service
4. รันคำสั่งอัปเกรดโมดูล
5. เปิด service
6. ทดสอบเมนูหลัก
7. ทดสอบสร้าง `Expense` 1 รายการ

## 10. วิธีถอนการติดตั้งแบบปลอดภัย

1. สำรองฐานข้อมูลก่อน
2. ตรวจว่าไม่มีงานค้างที่ต้องใช้งานโมดูลนี้
3. เข้า Odoo ด้วยสิทธิ์แอดมิน
4. ไปที่ Apps
5. ค้นหาโมดูลนี้
6. กด `Uninstall`
7. ทดสอบว่าเมนูและ action ของโมดูลหายไปแล้ว

## 11. ถ้าติดตั้งไม่ผ่าน ให้เช็กอะไร

ให้ดูตามนี้

1. dependency ครบหรือไม่
2. ชื่อโมดูลตรงกับโฟลเดอร์หรือไม่
3. path อยู่ใน addon path หรือไม่
4. ฐานข้อมูลและไฟล์ config ถูกต้องหรือไม่
5. log ของ Odoo มี error อะไร

## 12. สรุปสั้น ๆ

- คนทั่วไปอ่านหัวข้อภาพรวมก่อน
- แอดมินทำตามคำสั่งทีละขั้น
- หลังติดตั้งต้องทดสอบเมนู หมวดค่าใช้จ่าย และการส่งเอกสาร
- ก่อนอัปเกรดหรือถอนติดตั้ง ควรสำรองฐานข้อมูลทุกครั้ง
